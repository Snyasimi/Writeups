#Cloud computing


##Troubleshooting cloud issues
The following are steps in the compTIA troubleshooting methodolgy 
- Identify the problem
	This step includes questioning the user and idetifying any changes the user ahs recently made to the computer, back up data in the computer or other systems before making any changes to it yourself.

- Establish a theory of probable cause
	Begining with the symptoms, look for internal and external clues for what might be causing the problem.

- Test the theory to determine the cause
	After determinig the cause, and confirming your theory, decide what next steps you should take next. If you can't confirm your theory, try again or escalate the problem to the next support tier.

- Establish a plan of action to resolve the problem and implement the solution 
	however don't make any changes without considering policies and procedures and the impact the changes might have on other systems 

- Verify full system functionality and if applicable, implement preventive measures 
	THis might include educating the user
- Document the findings and outcomes 
	Since most orgs keep a knowledge base for systematic documentation, this info will be used in the future if the a similar problem, occurs

###Preventive measures 
To minimize the likelihood of problems cropping up in your cloud env, you shuld consider the following

- Maintain good monitoring and analysis techniques
- Thoughtfully configure your dashboards to show the most helpful information 
- Follow good change management processes
- Understand you cloud services, and how to identify where problems are likely to occur, how to locate these problems and ho best to address them
